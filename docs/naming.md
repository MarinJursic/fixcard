# Name due diligence

“Fixcard” is a concise working name, not a cleared trademark.

A preliminary web, GitHub, and package-registry search performed during project
creation found:

- an unrelated service at `fixcard.io` in aviation recruiting;
- ordinary uses of the words “fix” and “card” in issue titles and UI work;
- no known same-purpose developer CLI or Rust crate using the exact name at that
  time.

This search is time-bound, incomplete, jurisdiction-agnostic, and not legal
advice. Before a stable 1.0 launch, repeat registry/repository/domain searches,
check relevant trademark databases with qualified counsel if the project gains
material adoption, and choose a different name if confusion risk is meaningful.

The file format starts with `fixcard: 1`; a pre-1.0 rename would therefore need
a documented compatibility alias and migration rather than a silent schema
change.
